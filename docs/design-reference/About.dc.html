ABOUT

The longer version.

I’m Hasan. I live in Ankara, speak Turkish at home and English at work, and I’ve been writing software for a living since the end of 2019.

It started at Aselsan1, part-time at first, automating Excel and XML chores with Python and Django. Then three full-time years of React frontends, Spring Boot services and the Kubernetes clusters underneath them, plus the CI/CD glue in Bash and Go that kept it all moving.

1 — OpenShift, Rancher, MicroK8s. I’ve met them all.

In 2023 I moved to Scorp, working on livestreaming and moderation: Node and Python on the backend, Vue dashboards for streamers and the people keeping their chats sane. In 2024 I led the MVP of gardro.app2, an image-generation product, end to end.

2 — a lot of SDXL prompt wrangling, mostly to keep the outputs safe.

Since 2025 I’ve been independent3: freelance work in TypeScript and Python, and a lot of time with LLM-driven systems: prompts, evaluation loops, retrieval, tool use. And, of course, the small tools that end up on this site.

3 — this is where the agentic stuff took over my evenings.

What I reach for

TypeScript and Python most days. Go when I want a small, fast binary; Java when someone else’s system speaks it. React or Vue in front, Node, FastAPI, Django or Spring behind, Postgres underneath, and Docker and Kubernetes around the whole thing.
